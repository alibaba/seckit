# Security Policy

## Reporting a Vulnerability

Do not publish exploit details, proof-of-concept payloads, sensitive data, or credentials in public issues or pull requests.

GitHub private vulnerability reporting is enabled. Use **Report a vulnerability** on the [repository's Security page](https://github.com/alibaba/seckit/security) to submit a private report.

Include the affected SDK version, JDK version, relevant configuration, impact, and a minimal reproduction. Remove secrets and personal data. Coordinate disclosure with the maintainers before making details public.

## Versions

Please identify the affected release or commit and whether the issue reproduces on the latest available version. Version `0.1.1` is currently declared in the project metadata. No response-time commitment or maintenance policy for older versions is established by this document; confirm these with the maintainers.
